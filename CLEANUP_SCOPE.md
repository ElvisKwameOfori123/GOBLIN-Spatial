# Baseline-only cleanup scope

This branch separates deferred scenario development from the active historical GOBLIN-Spatial repository.

Active repository scope after this cleanup:

1. 2015-2025 historical ED baseline;
2. cattle and sheep biological cohorts;
3. land, farm structure and fixed-coefficient Standard Output;
4. ED, county, WFD catchment, GOBLIN-compatible catchment and national reporting views;
5. livestock signatures and parent-follower relationship-support geography;
6. historical evaluation and coherence audit;
7. illustrative 30% dairy/suckler spatial-attribution perturbation.

Deferred SC1/SC2/SC3, pathway, land-release and scenario-allocation code has been preserved separately in `ElvisKwameOfori123/GOBLIN-Spatial-SC` before removal from the active tree.

The cleanup is intended to change repository scope and reproducibility only. It must not change historical scientific calculations or released numerical results.
