# Reporting package

This package is downstream of frozen GOBLIN-Spatial scientific outputs.

It may:
- catalogue validated runs;
- create typed report-data tables;
- join frozen ED geometry;
- prepare publication figure-data extracts;
- render tables, maps and charts.

It must not:
- rerun SC1/SC2/SC3;
- change national pathway controls;
- reallocate livestock or released land;
- infer eligibility;
- solve SC3;
- recompute robustness or redistribution independently of the scientific synthesis layer.
