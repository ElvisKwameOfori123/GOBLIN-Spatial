# Instructions for coding agents

Before working in this repository, read:

1. `AGENT_WORKFLOW.md`
2. `AGENT_DECISIONS.md`
3. the current pull request description and discussion
4. the current branch diff
5. task-relevant scientific documentation

Follow the risk-scaled multi-agent protocol in `AGENT_WORKFLOW.md`.

Use the pull request, not a shared handover file, for live coordination between agents.

Important: do not silently change scientific mathematics or broaden task scope. When the task is historical-baseline only, SC1-SC3 are out of scope unless the human owner explicitly includes them.

Before stopping, leave any required review, question, implementation note or verification as a top-level PR comment.
