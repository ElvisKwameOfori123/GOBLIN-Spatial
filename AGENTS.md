# Instructions for coding agents

Before working in this repository, read:

1. `AGENT_WORKFLOW.md`
2. `AGENT_HANDOVER.md`
3. `AGENT_DECISIONS.md`
4. the current pull request and branch diff
5. task-relevant scientific documentation

Follow the multi-agent proposal/review/decision protocol in `AGENT_WORKFLOW.md`.

Important: do not silently change scientific mathematics or broaden task scope. When the task is historical-baseline only, SC1-SC3 are out of scope unless the human owner explicitly includes them.

Before stopping, update `AGENT_HANDOVER.md`.
